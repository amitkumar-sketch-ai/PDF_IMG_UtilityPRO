# PDF_IMG_UtilityPRO

Office tools that run fully in your browser and work offline. Nothing is uploaded anywhere.

| File | What it does |
|------|--------------|
| `Hamara_App.html` | **Hamara App**: PDF tools (merge, split, compress, organize, protect/unlock, convert, edit) and Image tools (compress, crop and resize, convert, filters, watermark, background, image to text, collage) |
| `Excel_clone.html` | A spreadsheet in the browser |

## How to use

Download the `.html` file and open it in Chrome or Edge. No install and no internet needed.

Live demo: https://huggingface.co/spaces/AMITJ12/PDF_IMG_UtilityPRO
